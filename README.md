# 🎮 PIXEL RUNNER · 像素风无限跑酷

> 一款纯 AI 生成的 2D 像素风无限跑酷游戏，侧滚动卷轴、自定义背景、难度递增、跳跃/躲避/攻击、金币收集、技能释放、商店升级与皮肤系统。

🎮 **在线游玩**：https://wanderwrs.github.io/pixel-runner/pixel-runner.html

| 模块 | 说明 |

## 🎮 操作说明

### 桌面端
| 按键 | 功能 |
|------|------|
| `空格` / `↑` | 跳跃 |
| `↓` | 滑铲躲避 |
| `J` | 攻击 |
| `K` | 释放技能 |
| `T` | 切换托管 |
| `Esc` | 暂停 |

### 移动端
触屏设备游戏开始后，屏幕底部自动显示 4 个圆形控制键：↑跳跃、↓躲避、⚔攻击、✦技能。

## 🛒 商店系统

跑酷获得的金币可在商店消费（消耗从金币总数扣除）：
- **属性升级**：跳跃力、攻击力、生命值、能量恢复等

- **皮肤购买**：稀有/传奇皮肤附带特殊加成
- **背景切换**：解锁并切换主题背景

## 🛠️ 技术栈

- **Canvas 2D API** —— 全部像素渲染
- **requestAnimationFrame** —— 60fps 游戏循环
- **localStorage** —— 本地存档（进度、设置、皮肤）
- **零依赖** —— 单 HTML 文件，无任何第三方库

### 架构分层
```
Data     数据层   —— 存档、金币、解锁状态
Config   配置层   —— 皮肤/背景/怪物/技能/升级定义
UI       界面层   —— 菜单、商店、HUD、面板
Game     引擎层   —— 游戏循环、物理、碰撞、生成
Render   渲染层   —— 像素绘制、背景、角色、怪物
```
