## 🎮 操作说明

### 桌面端
| 按键 | 功能 |
|------|------|
| `空格` / `↑` | 跳跃 |
| `↓` | 滑铲躲避 |
| `J` | 攻击 |
| `K` | 释放技能 |

## ⚔️ 攻击系统

按 `J` 攻击，攻击强化升级项支持 **1-10 级**，等级越高攻击范围越远、伤害越高：

- **每级加成**：攻击范围 +16px、伤害 +1
- **数值区间**：1 级（范围 74 / 伤害 2）→ 5 级（范围 138 / 伤害 6）→ 10 级（范围 218 / 伤害 11）
- **皮肤差异化**：不同皮肤拥有不同攻击类型与弹丸形态
  - 近战（即时命中）：剑弧形斩、长枪直线突刺
  - 远程（发射专属弹丸）：手里剑旋转飞镖、青色光束线、紫色发光法球、旋转火球、三发羽毛扇形扩散
- **弹丸系统**：玩家弹丸与敌方箭通过 `owner` 字段区分；冲刺/挥砍只击碎敌方箭，玩家弹丸不再误伤玩家

## 🛠️ 技术栈

- **Canvas 2D API** —— 全部像素渲染
- **requestAnimationFrame** —— 60fps 游戏循环
- **localStorage** —— 本地存档（进度、设置、皮肤）
- **零依赖** —— 单 HTML 文件，无任何第三方库

### 架构分层
```
Data     数据层   —— 存档、金币、解锁状态
Config   配置层   —— 皮肤/背景/怪物/技能/升级定义
UI       界面层   —— 菜单、商店、HUD、面板
Game     引擎层   —— 游戏循环、物理、碰撞、生成
Render   渲染层   —— 像素绘制、背景、角色、怪物
```
